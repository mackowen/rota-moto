# Rota Moto v39.6-ui-mobile-fix2

Base: Rota Moto v39.2.

## Alterações desta versão
- Finalização de corrida protegida por assinatura do cliente.
- Campo de assinatura desenhado na tela pelo cliente.
- Slider "Deslize para finalizar" fica desabilitado até existir assinatura.
- A corrida só muda para finalizada depois que o slider chega ao final.
- Assinatura e horário são persistidos junto ao registro da corrida.
- Assinatura fica disponível nos detalhes da corrida finalizada.
- Mantida a validação de distância/GPS antes da finalização.
- Fluxo de finalização no modo de trabalho também usa o mesmo processo.
